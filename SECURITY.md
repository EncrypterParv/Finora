# Security policy

Finora is a financial-data project. Do not report vulnerabilities with real
account numbers, credentials, transaction exports, tokens, or other sensitive
data in public issues or pull requests.

For a production deployment, report suspected vulnerabilities through a
private security channel configured by the repository maintainers. Include a
minimal reproduction, affected component, impact, and proposed mitigation.

All bank integrations in this repository are simulated. Any change that adds
real financial-provider credentials or stores sensitive data requires explicit
security review before implementation.
